Along the Twig

Identifies text obfuscation techniques used to mask potentially malicious code or content, such as character substitution, encoding, or insertion of whitespace, and reports the detected obfuscation types and a potential severity. What it looks for is disguise itself: text shaped and coloured to pass as its background, picked out only by patient looking.

What it does

The detector works on a file or text and reports which obfuscation types it finds. Usage, as the README gives it: ./analyze-text-obfuscation-detector [params]. Its one requirement is pandas.

Verified behavior

Severity is derived from how many of the three checks hit: none when no check hits, low for one, medium for two, and high for three; it appears in the console summary and in the output CSV. Base64 detection tests the whole file as one blob and also extracts candidate base64 tokens from the text and tests each one, so a base64 string embedded in ordinary prose is detected.

Stated limits

The usage line names no input file argument, even though the detector works on a file or text. How the material reaches the detector is not spelled out in the source. Licence: the README closes with a copyright line and names no licence.
