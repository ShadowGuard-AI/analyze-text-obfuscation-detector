Station one: what the listening is for

analyze-text-obfuscation-detector identifies text obfuscation techniques used to mask potentially malicious code or content, naming the three the source names: character substitution, encoding, and insertion of whitespace. It reports the detected obfuscation types and a potential severity, and it is focused on data analysis and reporting.

Station two: the severity scale

Severity comes from how many of the three checks hit. The scale appears in the console summary and in the output CSV.

None

No check hits.

Low

One check hits.

Medium

Two checks hit.

High

Three checks hit.

Sponge cluster note

No other grading words are added, and no example text is shown with a grade attached, because the source provides none.

Station three: the base64 listening

Base64 detection tests the whole file as one blob, and it also pulls candidate base64 tokens out of the text and tests each one, so a base64 string sitting inside ordinary prose is still detected. That second reach, into embedded strings, is this station's whole subject.

Station four: getting and running the tool

git clone https://github.com/ShadowGuardAI/analyze-text-obfuscation-detector
./analyze-text-obfuscation-detector [params]

Sponge cluster note
